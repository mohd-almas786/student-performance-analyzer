# Student Performance Analyzer

A Python-based **Student Performance Analyzer** that processes student marks and provides useful academic insights such as averages, grades, pass/fail results, rankings, and subject-wise performance.

## 📌 Features

* View all student records
* Search for a student by name
* Calculate student averages
* Assign grades and pass/fail results
* Identify the top-performing student
* Generate student rankings
* Calculate subject-wise averages
* Display pass/fail statistics
* Interactive command-line menu

## 🛠️ Technologies Used

* Python
* Pandas
* CSV
* Modular Python programming

## ⚙️ How It Works

The project loads student data from a CSV file and processes it to calculate:

* Average marks
* Grades
* Pass/Fail status
* Student rankings
* Subject averages
* Overall pass/fail statistics

The application then provides an interactive menu where users can select different analysis options.
